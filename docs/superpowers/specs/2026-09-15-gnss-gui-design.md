# GNSS BIN 解析工具图形界面（本地网页版）设计文档

- 日期：2026-09-15
- 项目：gnss_bin_parser（C++17 解析引擎 + 新增 Python 本地网页界面）
- 状态：已与用户逐节确认（形态与架构 / 功能细节 / 错误处理与测试）

## 1. 背景与目标

现状：解析工具是命令行程序（`gnss_parser.exe`），使用需要手敲参数；数据单品约 400MB，输出的 CSV 可达 700MB。
用户目标：**把数据"放进去"就能解析并看到结果**，不必记命令。

要做成：**本地网页界面**（浏览器里操作，双击启动脚本即用），具备
拖拽/选择文件、一键解析、实时进度、结果预览与图表、批量队列、结果打包与报告。

## 2. 范围与分期

| 阶段 | 内容 |
|---|---|
| **P1 能用** | 工具条（引擎路径/输出目录/自动开始）；原生"选择文件/文件夹"；批量队列（串行、入队即开始、取消/重试/清空）；实时进度；结束统计；概览卡片；输出文件列表；打开目录；设置与队列记忆 |
| **P2 好看** | 表格分页浏览（排序/按系统筛选）；六张图表；导出 PNG |
| **P3 好交付** | 解析报告（HTML + Markdown）；zip 打包（CSV + 报告 + 图表 PNG） |

> 实施顺序：**先出 P1 的实施计划并交付可用版本**；P2、P3 各自再出实施计划（本设计文档是三者共同的设计依据）。

非目标（YAGNI）：
- 不做远程/多用户访问（仅监听 127.0.0.1）
- 不做拖拽上传的断点续传
- 不引入地图底图/在线 CDN（保持完全离线）
- 本设计**不改动 C++ 引擎**（实时统计采用"进度实时 + 结果后统计"）
- 不做安装包/自动更新

## 3. 总体架构

单个 Python 3 进程（仅标准库），前端为一个静态页面：

```
浏览器页面（原生 JS/CSS + 本地 Chart.js 副本）
      │ HTTP / SSE（仅 127.0.0.1）
      ▼
gui/server.py
  ├─ 任务队列（串行，单工作线程；状态机）
  ├─ 引擎调用：subprocess → build\Release\gnss_parser.exe
  │     └─ 逐行读 stdout → 实时进度 / 结束统计
  ├─ 结果聚合：流式扫描 CSV → 统计 / 序列 / 行索引（缓存）
  └─ state.json：设置与队列记忆
      ▼
统一输出目录（CSV）
```

### 3.1 关键设计决策

1. **进程模型**：单 Python 进程 + 单工作线程，任务**串行**执行（避免磁盘争抢）。
   任务状态内存维护并持久化到 `gui/state.json`。
2. **实时进度来源**：调用 `gnss_parser.exe -i <file> -o <outdir> -p <prefix>`，逐行解析其 stdout：
   - `进度: NN% (x MB / y MB)` → 推送进度事件
   - 结束统计块（成功解析帧数 / 各日志帧数 / sync_lost / crc_error / malformed / unsupported / CSV 行数）→ 任务结果与概览卡片
3. **文件如何"放入"**（浏览器无法从拖拽获得真实路径）：
   - **主路径**：页面按钮 → 后端弹 **Windows 原生对话框**（Python 自带 tkinter）→ 返回真实路径，**零拷贝**直接解析（大文件唯一高效方式）
   - **兜底**：拖拽文件进页面 → 浏览器**上传副本**到临时目录后解析（界面明确提示"将复制一份"）
4. **大数据处理**：统计用流式逐行扫描（内存恒定）；图表数据服务端**分桶降采样**（默认每图 ≤2000 点）；表格浏览建立"每 5000 行一个字节偏移"的**行索引**后用 `seek` 分页，避免把百万行送到前端。
5. **原生对话框线程约束**：Windows 下 tkinter 对话框必须在主线程，因此后端以"隐藏 Tk 根窗口 + 请求队列"的常驻线程处理选择请求，HTTP 线程只做转发与等待。
6. **输出命名与冲突**：每个任务的输出前缀 = 输入文件名去掉扩展名并清洗非法字符；若目标目录已存在同名 CSV，自动追加 `-2`、`-3`…，**绝不静默覆盖**。所有 CSV 输出到统一输出目录。
7. **上传临时目录与缓存**：拖拽上传落盘到 `%TEMP%\gnss_gui_uploads\`，解析完成后按设置清理（默认删除）；结果聚合缓存的键 = CSV 路径 + 文件大小 + mtime，文件变化即失效。
8. **自动开始**：工具条"拖入即开始"默认**开启**，可关闭为手动点"开始解析"。

## 4. 页面设计

单页三区：

```
┌ 工具条：引擎路径(自动探测/可改) │ 输出目录(选择+记住) │ ☑拖入即开始 │ 清空队列 ┐
├ 左：任务队列 ─────────────┬ 右：选中任务详情（4 标签页）───────────────┤
│ 文件名 · 大小 · 状态徽标   │ ①概览 ②表格 ③图表 ④报告/打包              │
│ 进度条 · 耗时             │                                            │
│ 取消/重试/打开目录/删除    │                                            │
└───────────────────────────┴────────────────────────────────────────────┘
```

- **① 概览**：卡片（总帧数、RANGE/SATVIS2/BESTPOS 各多少、crc_error、malformed、unsupported、耗时、吞吐 MB/s）+ 星座分布柱图（简化版）+ 输出文件清单（点击打开所在目录）
- **② 表格**：数据集切换（range / satvis2 / bestpos）+ 分页 + 列排序 + 按卫星系统筛选
- **③ 图表**：见第 5 节，每图可导出 PNG，并标注"原始 N 点 → 显示 M 点"
- **④ 报告/打包**：生成报告、打包 zip（见第 6 节）

## 5. 图表定义（六张，服务端降采样）

| 图 | 数据来源与算法 |
|---|---|
| 卫星数随时间 | 按历元（TOW_ms）统计 RANGE 观测数，按卫星系统堆叠 |
| C/N0 载噪比 | 0.5 dB-Hz 分桶直方图 + 分系统 C/N0 中位数随时间的折线 |
| 定位轨迹与精度 | 经纬度散点（局部 ENU 近似投影）+ 高程与水平精度（`sqrt(LatStd²+LonStd²)`）随时间 |
| 星空图 | 选定历元的 (方位角, 仰角) 极坐标散点，按系统着色，带时间滑块 |
| 多普勒与原始趋势 | 分系统 Doppler 抽样散点 + 伪距-载波一致性（`PSR/λ − ADR`）随时间 |
| 分系统概览 | 各系统观测数/卫星数柱状图 + 占比饼图 |

- **伪距-载波一致性需要"信号类型 → 波长"表**：从 RANGE 的 `ChTrStatus` 提取信号类型（bit21-25），按官方信号类型定义映射到频率（GPS L1/L2/L5、北斗 B1I/B2I/B3I/B1C/B2a、GLONASS G1/G2、Galileo E1/E5a/E5b 等），未知类型跳过并计数。该表内置于 GUI（Python），不依赖引擎改动。
- 「概览」页的星座分布柱图是简化版（按行数占比），完整的分系统图表在「图表」页。
- 降采样规则：按时间等宽分桶，桶内取均值（计数类取最大值），默认目标 2000 点，可调。

## 6. 报告与打包（P3）

- **报告内容**：文件信息（名称/大小/SHA256 前 16 位/解析耗时）、帧统计与异常计数、星座分布表、时间跨度与采样率、各数据集行数与列说明、六张图 PNG、生成时间与工具版本
- **产出**：`report.html`（图片内嵌）+ `report.md`；**zip 包** = CSV + 报告 + PNG

## 7. 接口一览（REST + SSE，仅 127.0.0.1）

```
GET  /                                    静态页面
GET  /api/settings                        读取设置
POST /api/settings                        保存设置（引擎路径/输出目录/自动开始）
POST /api/pick/files                      原生对话框选 .bin（可多选）→ 真实路径
POST /api/pick/folder                     原生对话框选文件夹（批量导入其中 .bin）
POST /api/upload                          拖拽兜底：流式落盘
POST /api/jobs                            入队（paths[]）
GET  /api/jobs                            队列快照（用于断线校准）
POST /api/jobs/{id}/cancel|retry|remove   单任务操作
POST /api/jobs/clear                      清空（可保留运行中）
GET  /api/events                          SSE：job_added / updated / progress / finished
GET  /api/results/{id}/summary            聚合统计（缓存）
GET  /api/results/{id}/series             图表序列（chart=…&maxPoints=…）
GET  /api/results/{id}/rows               表格分页（dataset/offset/limit/filter/sort）
GET  /api/results/{id}/skyplot            某历元星空图数据（epoch=TOW_ms）

POST /api/results/{id}/package            打包 zip（请求体含图表 PNG）
POST /api/open                            在资源管理器中打开输出目录/文件
```

## 8. 错误处理

| 场景 | 处理 |
|---|---|
| 找不到引擎 exe | 启动按序探测：`GNSS_PARSER_EXE` → `build/Release/gnss_parser.exe` → `build/gnss_parser.exe`；都没有则顶部黄色横幅 + 手动选择，任务不入队 |
| 输入不存在/无权限/0 字节/非 OEM7（无同步头） | 任务标 **失败**，显示引擎退出码与关键输出行；区分"完全失败"与"解析 0 帧" |
| 输出目录不可写 / 磁盘满 | 解析前试写预检；解析中显示引擎的"CSV 写入错误: N" → 任务标 **完成但有警告** |
| 空间不足 | 按经验系数估算输出体积（实测 415MB 输入 ≈ 700MB CSV，≈1.7×）并提示，允许继续 |
| 运行中取消 | 终止子进程树 → 标 **已取消**，保留部分 CSV 并提供"保留/删除"选择 |
| 界面/服务重启 | 状态写 `gui/state.json`；启动时把残留 **running** 任务标为"已中断（可重试）" |
| SSE 断线 | 前端自动重连 + `GET /api/jobs` 快照校准 |
| 聚合遇到坏行/半截文件 | 逐行容错跳过并计数，界面显示"跳过 N 行" |
| 端口被占用 | 8765 起自动向后试到 8780；启动脚本打开实际端口 |

## 9. 测试计划

- **单元测试**（`unittest`，零依赖）：进度行解析、任务状态机（入队/运行/取消/重试/中断）、CSV 流式聚合（小 fixture）、降采样分桶、行索引分页、报告生成、zip 打包、各 API 处理器
- **端到端测试**：复用 `tests/regression.py` 的构造帧思路生成小 `.bin`（含 RANGE/SATVIS2/BESTPOS）→ 经界面后端入队解析 → 断言统计与直接运行 exe 一致；覆盖"空文件/垃圾文件/坏 CRC"的失败与警告路径
- **性能验证**（真实 415MB 数据）：进度更新 ≥1 秒级、统计耗时 <15 秒、界面进程内存峰值 <500MB
- **手工验收清单**：拖拽小文件；按钮选大文件；批量 3 个文件串行；取消运行中任务；重启后队列仍在；六张图出图并导出 PNG；zip 可解压

## 11. P1 验收标准

双击 `start_gui.bat` → 浏览器自动打开 → 选择（或拖入）一个 `.bin` → 队列出现任务 →
**进度实时走动** → 完成后显示帧统计与星座分布 → 可一键打开输出目录；
批量 3 个文件串行跑完；取消/重试可用；重启界面后设置与队列仍在。
